# HR Dashboard Project 📊

A Tableau workbook analyzing HR data — attrition trends, job satisfaction, and department-level KPIs.

## 🔍 Overview

This project explores an HR dataset to surface insights around employee attrition, job role satisfaction, and departmental performance using Tableau.

## 📁 Contents

- `HR_Analytics_Dashboard.twb` — Tableau workbook (source file). Open with [Tableau Desktop](https://www.tableau.com/products/desktop) or [Tableau Public](https://public.tableau.com/) to view.
- `HR Data.xlsx` — Underlying dataset used by the workbook.

## 📈 What's Inside

**Sheets included:**
- All KPI — summary view of key HR metrics
- Attrition by Gender
- Department wise Attrition
- Donut chart of job role distribution (built from two pie charts)
- Job Role Satisfaction Rating (calculated from employee ratings by role)
- Calculated fields + Histogram using bins, parameters, and gradient color scales

## 🛠️ Tools Used

- Tableau (workbook version 18.1 / Tableau 2026.2)

## 🚀 How to View

1. Download `HR_Analytics_Dashboard.twb` and `HR Data.xlsx`
2. Open the workbook in Tableau Desktop, **or**
3. Publish/upload it to [Tableau Public](https://public.tableau.com/) for a free, shareable, interactive version
